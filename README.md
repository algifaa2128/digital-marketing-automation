# Digital Marketing Automation

Sistem untuk membantu pekerjaan digital marketing melalui modul
yang dikembangkan secara bertahap.

## Modul yang direncanakan
1. Planning Ads
2. Generate UTM
3. Reporting
4. Ads Brief ke Agency
5. Monitoring

## Fokus pengembangan pertama: Generate UTM

Alur:
1. Pengguna memasukkan brief campaign.
2. Sistem memvalidasi kelengkapan informasi.
3. Sistem membuat link UTM sesuai aturan penamaan.
4. Hasil disimpan sebagai spreadsheet baru di folder Google Drive yang tersedia.
5. Link spreadsheet dikirim kembali ke pengguna.

Input awal direncanakan melalui Telegram atau Discord.
Dashboard web dapat ditambahkan pada tahap berikutnya.

## Prinsip pengembangan
- Pisahkan kode, konfigurasi, dan data campaign.
- Aturan penamaan serta template dapat dikonfigurasi.
- Jangan menyimpan password, token, atau API key di repository.
- Modul UTM menjadi bagian dari sistem yang lebih besar.

## Teknologi
Ditentukan setelah kebutuhan dan workflow dikonfirmasi.
